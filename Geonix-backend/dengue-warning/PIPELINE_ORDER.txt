RECOMMENDED EXECUTION ORDER
===========================

1) Install Python packages
   pip install -r backend\requirements.txt

2) Ensure model artifacts are present in Geonix-backend\dengue-warning\model\
   - Geonix-backend\dengue-warning\model\dengue_model.pkl
   - Geonix-backend\dengue-warning\model\features.pkl
   - Geonix-backend\dengue-warning\model\scaler.pkl

3) Start FastAPI scoring backend
   uvicorn backend.api.main:app --reload --host 0.0.0.0 --port 8000

4) Request risk score from mobile app backend route
   POST /score with required engineered features
   Set use_gemini=true to apply Gemini calibration

ZONE THRESHOLDS USED
--------------------
Low:    weekly_cases < 20      or risk_score < 0.35
Normal: weekly_cases 20-60      or risk_score 0.35-0.65
Danger: weekly_cases > 60       or risk_score > 0.65 (daily push)

NOTES
-----
- Firebase can remain the app database/notification channel.
- PostGIS should be a separate spatial service for polygon containment queries.
